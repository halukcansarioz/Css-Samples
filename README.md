# 🎨 CSS Samples & UI Components

Welcome to the **CSS Samples** repository! This project is a curated collection of various CSS components, creative animations, responsive layouts, and modern UI elements. It serves as a personal playground and a reference guide for front-end styling techniques.

The courses I take are on these topics and I develop projects on my own. This repository is a practical collection of my front-end experiments and CSS learning journey!

## ✨ What's Inside?

This repository contains various independent folders/files, each demonstrating a different CSS concept:

*   **UI Components:** Custom-styled buttons, profile cards, navigation bars, and forms.
*   **Animations:** Smooth CSS transitions, hover effects, and `@keyframes` animations.
*   **Modern Layouts:** Practical examples of CSS Flexbox and CSS Grid alignments.
*   **Responsive Design:** Mobile-first styling approaches using media queries.

## 🛠️ Tech Stack

*   **Markup:** HTML5
*   **Styling:** CSS3 (Vanilla CSS)
*   **Version Control:** Git & GitHub

## 🚀 Getting Started

Since this repository consists of pure HTML and CSS files, you do not need any complex local server, build tools, or dependencies to view the samples.

### Installation & Viewing

1.  **Clone the repository:**
    
    ```bash
    git clone https://github.com/halukcansarioz/Css-Samples.git
    ```

2.  **Navigate to the project directory:**

    ```bash
    cd Css-Samples
    ```

3.  **Explore the Samples:**
    Browse through the folders. To see a specific sample in action, simply double-click its `index.html` file to open it directly in your favorite web browser (Chrome, Firefox, Safari, etc.).

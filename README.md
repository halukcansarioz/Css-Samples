## About the Project
This project was created to explore the visual and layout capabilities of CSS, understand how styles cascade, and master modern layout systems like Flexbox and Grid. Each example focuses on a specific concept with clean, commented code.

- **Developer:** Haluk Can SARIÖZ
- **Languages:** CSS (primary), HTML (structure)
- **Purpose:** Hands‑on practice with CSS fundamentals and advanced techniques

---

## What You'll Find
The examples in this repository cover, among others:

- **Selectors & Specificity:** Class, ID, attribute, and pseudo‑class selectors
- **Box Model:** Margin, padding, border, and content area
- **Positioning:** Static, relative, absolute, fixed, sticky
- **Flexbox:** Alignment, ordering, wrapping, and flexible sizing
- **CSS Grid:** Two‑dimensional layouts, grid areas, and template rows/columns
- **Responsive Design:** Media queries, mobile‑first approach, fluid typography
- **Transitions & Animations:** Hover effects, keyframes, transforms
- **Custom Properties (CSS Variables):** Reusable design tokens
- **Practical Demos:** Navigation bars, cards, modals, and simple page layouts

All examples are standalone HTML files with embedded CSS, ready to open in any browser.

## Project Structure
The repository is organized into topic‑based folders for easy navigation:

```text
Css-Samples/
├── 01-selectors/               # Selector types and specificity
├── 02-box-model/               # Margin, padding, border, content
├── 03-positioning/             # Static, relative, absolute, fixed, sticky
├── 04-flexbox/                 # Flex container and item properties
├── 05-grid/                    # Grid container, rows, columns, areas
├── 06-responsive/              # Media queries and mobile-first design
├── 07-animations/              # Transitions, transforms, keyframes
├── 08-practical-components/    # Navbars, cards, modals, etc.
└── README.md                   # This file
```

*(Actual folder names may vary – each folder contains an `index.html` and optional `style.css` or inline styles.)*

## Installation & Usage

No build tools or dependencies are required. To view the examples:

**1. Clone the repository:**
```bash
git clone https://github.com/halukcansarioz/Css-Samples.git
cd Css-Samples
```

**2. Open any example:**
Double‑click the `index.html` file inside any topic folder, or use a live server (e.g., VS Code Live Server) for a better experience.
